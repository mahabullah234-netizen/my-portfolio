# Md Mahabullah Mahmud

Portfolio website of Md Mahabullah Mahmud, AI-Based Web Designer.

## Publish on GitHub Pages

1. Sign in at github.com and click **New repository**.
2. Name it `YOUR-USERNAME.github.io` (replace with your GitHub username) and set it to **Public**.
3. Click **uploading an existing file** and upload everything in this folder:
   `index.html`, `style.css`, `favicon.ico`, `site.webmanifest`, `robots.txt`, `.nojekyll`, `README.md` and the `assets` folder.
4. Click **Commit changes**.
5. Open **Settings → Pages**. Under **Build and deployment**, choose **Deploy from a branch**, select branch `main` and folder `/ (root)`, then **Save**.
6. After a minute or two the site is live at `https://YOUR-USERNAME.github.io/`.

## One thing to edit

In `index.html`, replace `YOUR-USERNAME` with your GitHub username in the two `og:image` / `twitter:image` lines. This makes the share preview picture appear when the link is posted on Facebook, LinkedIn, WhatsApp and similar.

## Files

- `index.html` – the page
- `style.css` – all styles
- `assets/` – profile photo, favicons, app icons and the 1200×630 share image
